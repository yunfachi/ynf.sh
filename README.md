# ynf.sh

My personal website, built with Nix and no JavaSlop.

Just open it: https://ynf.sh/

<img src="screenshot.png" alt="Screenshot of ynf.sh">

## Build

```sh
nix build .#site
```

The generated website will be available in `result/`.
